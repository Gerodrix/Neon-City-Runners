# Neon City Runners

Slot HTML5 cyberpunk desarrollada como proyecto de portfolio para aplicar a estudios de iGaming (Pragmatic Play, Red Tiger, Nolimit City, etc.).

## Stack
- **Frontend:** TypeScript + Vite + PixiJS
- **Backend:** Node.js + TypeScript + Express

## Mecánicas
- Grid 5x4, 12 líneas de pago
- **Core AI**: símbolo generador que crea Wilds (Glitch) en posiciones aleatorias
- **Data Vault (Scatter)**: activa Heist Free Spins
- Free Spins con Cores pegajosos (en desarrollo)

## Estado del proyecto
🚧 En desarrollo — ver [docs/project-management](./docs/project-management) para el backlog.

## Cómo correrlo

```bash
cd server && npm install && npm run dev
cd client && npm install && npm run dev
```
